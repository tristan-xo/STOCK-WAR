# Project Structure

- `server.js` — backend API, database setup, authentication, trading engine and admin controls
- `public/index.html` — application shell
- `public/app.js` — player and admin interface
- `public/styles.css` — UI styling
- `stockwars.db` — created automatically after first run
- `.env.example` — configuration template
- `EVENT_SETUP.md` — suggested event operating procedure
- `STOCK_LIST.csv` — seeded stock list
- `README.md` — installation and deployment guide
